      <p>The Image Slider is a simple web development project made using HTML, CSS and JavaScript. This project displays different images one by one in a slider. It contains five different images with their titles and descriptions. Users can change images using the Previous and Next buttons. The images also change automatically after every 3 seconds. This project helps us understand the basic working of image sliders and how HTML, CSS and JavaScript work together.</p>
    </hr>
      <li><h2>What is included in this project</h2></li>
    </hr>
      <p>This project includes five different images with their titles and descriptions. It has Previous and Next buttons to manually change the images. It also includes an automatic image-changing feature, fade-in animation and mouse hover functionality to pause and resume the slider. Font Awesome is used to display arrow icons on the buttons. The project also includes responsive CSS so that the slider can adjust to different screen sizes. Overall, this project demonstrates the use of HTML, CSS and JavaScript to create a simple and interactive image slider.</p>
    </hr>
      <li><h2>How this project is made</h2></li>
    </hr>
      <p>First, HTML is used to create the basic structure of the image slider. It includes an image section, title, description and Previous and Next buttons. CSS is used to design the slider by setting its height, width, background, image size, button styles and text positions. It also includes a fade-in animation and responsive design for smaller screens. JavaScript is used to store five images in an array and display them one by one. Functions are created to move to the next and previous images. The setInterval() function is used to change images automatically after every 3 seconds. The automatic slider stops when the mouse enters the slider and starts again when the mouse leaves.</p>
